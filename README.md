# もはじき Ver.2.1 — 2台オンライン対戦対応

ASOBeatの「もはじき」Ver.2.0（独立制作版）をベースに、**異なる2台のスマートフォンやPCから、ルームコードで入室して対戦**する機能を追加した版です。オリジナルの公開サイトを直接改変したものではありません。

## 今回の追加機能

- 「🌐 2台で対戦」モード
- **8文字のルームコード**で部屋作成・参加
- **招待URLのコピー・スマホの共有機能**（HTTPSの公開URLで利用可能）
- ルーム作成者（P1）が陸・海を選択してゲーム開始、参加者（P2）は自動でゲームへ移動
- **盤面・スコア・残り投数・地形・21種類の合体を同期**
- 物理演算はホスト側のみで実行するため、双方の判定差を防止
- 自分の手番でのみ発射可能。相手の端末からの不正な手番外入力を拒否
- ホスト側での通信断によるゲーム一時停止・参加者の再接続・進行中の盤面復元
- 試合終了後、**2人がそれぞれ「もう一戦」を選ぶと再戦**
- CPU対戦、スマホ1台の交互対戦、図鑑、カメラ背景も継続

## 2台での遊び方

**最初に：** ゲーム一式をHTTPSの静的Webホスティングに公開してください。2台が**同じ新URL**を開ける状態にします。すでに公開済みのURLへ上書きする必要はありません。

1. **スマホA：** 新URLを開く → 「🌐 2台で対戦」→「＋ 対戦ルームを作る」
2. **スマホA：** 表示された8文字コードか「招待URLをコピー」を友だちに送る
3. **スマホB：** 招待URLを開くと自動参加。あるいは新URLを開き「🌐 2台で対戦」→コード入力→「参加する」
4. **スマホA：** 「2人そろったらスタート！」ボタンを押す
5. 先攻P1（スマホA）と後攻P2（スマホB）が交互に6投ずつ対戦。スコア・盤面は自動同期
6. 試合後は双方が「もう一戦」を選ぶと同じ部屋で再戦

**注意：** ルームは一時的で、ホストがブラウザを閉じると維持されません。相手が切断したときは一定時間接続を待ち、再参加で復帰できます（ホストのページが生きている必要があります）。

## 公開に必要なファイル

- `index.html`
- `style.css`
- `game.js`

3ファイルを**同じフォルダ**に配置してください。GitHub Pages / Vercel 等、HTTPS対応の静的ホスティングで公開できます。

`mohajiki-v2.1-online.html` はスタイルとゲームロジックをまとめた**単一HTML版**です。動作確認用として使えますが、2人でURLを共有するにはHTMLをWeb公開する必要があります。

## 通信技術と制約

**WebRTC + PeerJS 1.5.5** によるP2P（ブラウザ同士の直接通信）を採用しています。PeerJS Cloudは2台の発見・接続開始のために利用し、ゲーム盤面の同期データはWebRTCデータチャネルで通信します。PeerJS JavaScriptは利用時にCDNから読み込まれます。

- 自分でゲーム用のバックエンドを用意せず、簡易ネット対戦を試せます。
- 外部の無料シグナリング基盤に依存します。利用状況やサービス障害によって接続できない場合があります。
- **一部のモバイル回線・厳しいNAT環境ではP2P接続できません。** 安定した一般公開・大規模運用には、自前のシグナリング基盤やTURNリレーの導入を検討してください。
- カメラ映像は相手に送信しません。送るのはゲーム進行データです。
- ホスト側が物理演算を担当するカジュアル対戦です。賞金や厳格なランキング向けの不正対策には、サーバー権威方式が必要です。
- オンライン対戦中の「ひとつ戻す」はゲーム公平性のため無効です。
- 盤面はオンラインでは600×800の共通座標系で計算され、画面の縦横が異なっても一致します。
- WebRTC通信は常に成功するとは限らず、ホストがページを閉じた試合のサーバー復元はできません。

参照：<https://peerjs.com/server/cloud> / <https://peerjs.com/client/faq>

## 検証（2026-10-22）

Chromiumで**2画面間の模擬通信**を用いて確認：

- ルーム作成と8文字コード参加、両端末の接続状態
- 同一の初期盤面の共有
- P2がP1の手番を操作できないこと
- P1→P2の交互投球、盤面・残り投数・スコア同期
- P2のマウスドラッグ中、複数回の同期を受けてもドラッグが中断しないこと
- 切断したP2が再入室し、元の盤面に復帰すること
- **12投での試合終了、両端末の勝敗画面**（テスト短縮用のターン進行を使用）
- **双方の合意による再戦**
- 旧モード（CPU・1台2人対戦）のブラウザ回帰テスト
- これらの検証でページ実行時のJavaScript例外は検出されませんでした。

**未検証：** 実際のPeerJS Cloud/WebRTCを使ったインターネット越しの2端末通信（検証環境の外部ネットワーク接続制限による）、iPhone Safari / Android Chrome実機のネット対戦、異なる通信キャリア同士の接続率、21種類の合体すべての物理的なバランス。

**公開URLはZIPを生成しただけでは発行されません。** 別URLが必要な場合は、新しく静的サイトとしてデプロイしてください。
