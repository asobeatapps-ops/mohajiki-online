# もはじき Ver.2.3 ONLINE

GitHub Pages向け分割版です。

## 主な変更
- 上下左右すべてを場外に変更。物理壁と壁反射を完全撤去。
- 衝突強度を3段階化。火花、衝撃波、ヒットストップ、画面シェイク、BANG/CRASH表示を追加。
- 短時間の連続衝突で HIT 表示と演出を強化。
- 強い場外に KNOCK OUT 演出を追加。
- 通常文字の押し出し +10、相手の合体駒 +30、自爆は0点。連続場外は最大+20のOUT COMBO。
- 盤上の駒が8枚未満になった場合、1試合最大8枚まで文字を補充。
- CPUは壁なし盤面を考慮し、端の相手駒を狙いやすく、無目的な投球は中央方向を優先。
- 設定に「画面揺れ ON/OFF」を追加。
- オンライン対戦プロトコルを Ver.2.3 に更新。Ver.2.2とは対戦できません。

## GitHub Pages
このフォルダ内のファイルをリポジトリ直下へアップロードしてください。
`tools/vendor_assets.py` と素材関連ファイルはVer.2.2からそのまま利用できます。

## 写真素材
`ASSET_CREDITS.md` とゲーム内 PHOTO CREDITS を参照してください。
`python tools/vendor_assets.py` をPCで実行すると、許諾情報付き素材をローカル配信用に取得できます。
