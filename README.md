# もはじき Ver.2.2 ONLINE / OVERDRIVE

既存のVer.2.1 ONLINEをベースにした改修版です。新規公開・GitHubの更新は自動では行っていません。

## GitHub Pagesへの反映

すでに公開しているリポジトリの、現在のindex.htmlと同じ階層に、ZIPを展開した中身をアップロードしてください。ZIP自体を置いても更新されません。

必須ファイル：index.html / style.css / game.js / assets.js / assets-local.js

画像の出典・ライセンスを残すため、ASSET_CREDITS.mdとassets-manifest.jsonも同梱してください。ゲーム内にもPHOTO CREDITSがあります。

別添の「mohajiki-v2.2-online.html」はCSS/JSを内包した1ファイル版です。こちらをindex.htmlに改名し、旧index.htmlだけを差し替えても動作します。写真とオンライン通信ライブラリはネット経由で読み込みます。

更新後は両端末でページを再読込し、BATTLE LAB 2.2と表示されることを確認してから新しい部屋を作ってください。Ver.2.1との混在対戦はできません。

## 改修内容

- 仲間の写真カード選択：21タイプ、37種類の見た目。文字駒は文字のまま、合体後に選んだ写真を表示。
- 草・坂・氷・温泉・花・波・渦の画像レイヤー。範囲と効果と残りターン数を併記。
- OVERDRIVE：最大初速995→1690（約1.7倍）、減速を緩め、壁・駒の反発を強化。突進・周囲への衝撃を中心に1.45倍、坂・波・渦の加速係数1.65倍。物理速度上限2200。
- 物理演算は1/240秒の固定刻み。速度上限・衝突解決・最大移動時間を併用。短い引きで微調整、長く引くと大きく加速する非線形カーブ。
- 合体駒を拡大、P1の丸・P2の菱形バッジ、残像・衝撃波・パワーリングを追加。
- 引っ張り中に別指でタップすると取り消し。盤面外のタップも対象。全指を離すまで再発射しません。投数減算・通信発射なし。PCはEsc、右クリックも対応。
- 画面回転・中断・メニュー表示・ポインター解除時は引っ張りを破棄。
- 仲間とパワーは試合開始時に固定。オンラインはP1/P2が各自の仲間を選択。
- 強化した投球をゲスト側から送っても受理するよう、通信側の速度検証も更新。
- 動かせる駒がない場合は自動パス。盤面が空になっても試合が終了まで進みます。

得点・21合体・6投ずつ・地形の種類・CPU・1台交互・2台通信・図鑑・カメラ背景は維持しています。

## 写真の読み込み方式（重要）

このZIPには写真の画像バイトを一括同梱していません。画像の出典・作者・ライセンスと読込先URLを登録し、初期状態ではWikimedia Commonsから読み込みます。通信制限や配信元の都合で取得できない場合は代替表示になります。

画像は同時3件まで、表示予定のものを優先して読み込みます。写真読込待ちでゲームを停めません。設定から画像の再読込・写真OFFも可能です。

本環境では外部画像のバイト取得ができないため、実写真の表示・トリミング・全URLの配信成功は未検証です。画像の読込・選択反映・Canvasの切り抜き描画は合成テスト画像で確認しました。

### 任意：写真を自分のGitHubに同梱する

通信可能なPCで、展開したフォルダ内から実行：

```sh
python tools/vendor_assets.py
```

成功した画像はassets/に保存され、assets-local.jsが更新されます。この2つもGitHubにアップロードすると、その画像は自分のサイトから配信されます。出典・ライセンス表示は削除しないでください。この手順は分割ファイル版用です。取得スクリプトは構文確認済み、実取得は未検証です。

## 通信について

既存のPeerJS 1.5.5とホスト主導の状態同期を維持。新たな有料APIは追加していません。ホストはページを開いたままにしてください。通信確立は外部シグナリング・各回線の制限に依存します。TURN中継サーバーの追加は行っていません。

模擬通信の2画面テストは実施済みですが、実際のシグナリング・WebRTC・2台実機・回線をまたぐ接続は未検証です。iPhone Safari実機、カメラ、実機性能、長時間の対戦バランスは未検証です。
